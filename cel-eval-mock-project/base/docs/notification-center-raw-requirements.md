# 用户通知中心 —— 原始需求（T12 项目设计用）

> 以下需求包含模糊点、冲突和不完整信息。需要你梳理澄清。

## 功能描述

系统需要支持向用户发送通知。

## 需求列表

1. **通知渠道**：支持邮件和短信通知。
2. **发送方式**：需要实时推送，同时每天汇总发送一次。
3. **用户范围**：支持所有用户。
4. **消息内容**：通知内容包括标题、正文、发送时间。
5. **去重**：未提及。
6. **失败处理**：未提及。
7. **优先级**：未提及。
8. **模板**：需要支持自定义通知模板。

## 非功能需求

- 性能：需要支持高并发。
- 安全：消息内容需要加密。

## 约束

- 项目上线时间为下个月。
